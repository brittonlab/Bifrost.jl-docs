Usage

Building Blocks

These files are intentionally useful on their own:

FileStandalone role
material-properties.jlTogether with the other files in src/material/, provides material constants and spectra; no path or fiber geometry.
path-geometry.jlThree-dimensional path construction and geometric queries; no optics.
path-integral.jlAdaptive propagation for callable K(s) and Kω(s) generators.

The fiber-specific layers combine those pieces:

FileHow it extends the standalone pieces
cross-section.jlTogether with the other files in src/fiber-cross-section/, adds step-index fiber optics and birefringence responses.
fiber-path.jlBinds path geometry to a cross section and assembles bend/twist K and Kω.

Current Model

High-level authoring is path based:

  1. Author geometry on a PathBuilder: segment verbs append segments in order, and spin! opens material-spin runs.
  2. Place it with build(pb), producing a Path for geometry queries.
  3. Bind it to a FiberCrossSection subtype with Fiber(pb; cross_section, T_ref_K), which builds the path and applies its :T_K/:tension strain, or with FiberModel(pb; cross_section, T_ref_K) when authored values are uncertain.
  4. Propagate at a requested wavelength with propagate_fiber(fiber; λ_m=...).

A path starts at PathBuilder(; point, outgoing_tangent) (default: the origin, heading +z) and ends at the exit of its last segment. The segment verbs and the segments they append:

VerbSegment
straight!StraightSegment
bend!BendSegment (circular arc)
helix!HelixSegment
catenary!CatenarySegment
jumpto!JumpTo (connector)

Each segment is written in the frame the previous one ends in, so tangent continuity holds by construction and axis_angle orients a bend, helix or catenary in that frame. jumpto! is the exception: it appends a JumpTo, a connector to a global target point (with an optional global incoming_tangent there), whose shape depends on where it is placed. build resolves it into a CubicConnector — a G1 cubic Hermite curve matching position and tangent at both ends, curvature free — honoring min_bend_radius or a target_length (src/geometry/path-geometry-connector.jl). A connector may sit anywhere in a path, any number of times, with segments after it.

Mechanical twist is set per segment with the twist keyword on the segment verbs as a constant rate (rad/m, including an MCM Particles). Vary twist along a path with consecutive constant-twist segments. Material spin is authored in runs: spin!(pb; rate) covers every segment appended after it until the next spin!, with rate nothing, a constant, or a Function of run-local material arc length; the spin phase is continuous along the whole path.

The optical Fiber stores:

  • the built Path,
  • the FiberCrossSection,
  • a reference temperature T_ref_K,
  • the fiber domain [s_start, s_end].

The operating wavelength is not stored on Fiber. It is supplied per query to generator_K(fiber, λ_m), generator_Kω(fiber, λ_m), propagate_fiber, and propagate_fiber_sensitivity.

For runnable code, see the Quick start and Examples. The Theory pages cover the generator formalism, propagation, and DGD sensitivity.
