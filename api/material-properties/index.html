MaterialProperties

Intrinsic optical material properties — refractive index, thermo-optic behavior, CTE, and the spectral responses and derivatives used by downstream cross-section and DGD calculations. No path or fiber geometry lives here.

Bifrost.MaterialProperties.MATERIAL_PROPERTY_API — Constant
MATERIAL_PROPERTY_API

The material property API as (function, arity) pairs, material argument included. Every concrete AbstractMaterial defines each method with untyped non-material arguments; a deliberately unmodeled property throws UnsupportedPropertyError. Package load fails with MaterialAPIError for any material missing a method, so adding an entry imposes the property on every material.

Bifrost.MaterialProperties.AbstractMaterial — Type

Material properties for optical glasses.

This file defines base types and common algebraic methods that will be available to all specific materials defined in the material folder.

Units (SI unless noted):

  • λ wavelength in m
  • T_K temperature in K
  • xge, xf dopant molar fraction (dimensionless; range is per-material)
  • refractive indices, Poisson ratio, photoelastic constants: dimensionless
  • cte 1/K
  • softening_temperature K
  • youngs_modulus Pa
  • nonlinearrefractiveindex (n_2) m²/W

Every concrete material defines each method in MATERIAL_PROPERTY_API, returning a value or throwing UnsupportedPropertyError; package load fails with MaterialAPIError for a material that does not.

Bifrost.MaterialProperties.brillouin_gain_peak — Method
brillouin_gain_peak(glass::SilicaGermaniaGlass, λ, T_K) -> m/W

Peak Brillouin gain coefficient, anchored at the pure-silica value SILICA_BRILLOUIN_GAIN_PEAK and scaled by the bulk-mixing doping corrections (p₁₂, ρ, v_A) and the textbook 1/λ² dependence. The opto-acoustic overlap and the mode-index factor are not modelled, so the absolute value is uncertain — pass a measured g_B where it matters. Ge doping shifts the Brillouin response weakly over the supported ≤5 mol% range (Deroh et al., Opt. Lett. 43, 4005 (2018), doi:10.1364/OL.43.004005).

source
Bifrost.MaterialProperties.brillouin_linewidth — Method
brillouin_linewidth(glass::SilicaGermaniaGlass, T_K) -> Hz

Brillouin gain FWHM linewidth. Returns the fused-silica value SILICA_BRILLOUIN_LINEWIDTH_HZ across the supported ≤5 mol% GeO₂ range, where the doping dependence is within measurement scatter; it grows strongly only at heavy doping (≈28→98 MHz over 3.6→98 mol%, Deroh et al., Opt. Lett. 43, 4005 (2018), doi:10.1364/OL.43.004005), a range the material model rejects at construction.
