PathIntegral

Adaptive propagation of the Jones equation dJ/ds = K(s)J and the coupled sensitivity system for G = ∂ωJ, with breakpoint-aware interval decomposition, phase-insensitive error control, and MCM-friendly closed-form matrix exponentials and DGD extraction. The Theory section derives the underlying generators.

Bifrost.PathIntegral.FiberPropagationResults — Type
FiberPropagationResults

Eagerly stored observables of a fiber propagation run, the return type of propagate_fiber(model::FiberModel; ...) and of the wavelength-sweep form propagate_fiber(fiber; λ_m::AbstractVector).

Per deterministic case i (case value driving_values[i], one per queried wavelength):

  • J[i], J_dw[i]: output Jones matrix and its angular-frequency sensitivity.
  • dgd[i]: differential group delay in seconds (output_dgd_2x2). J_dw and dgd are nothing for a run with sensitivity = false, and dgd on such results throws a MissingSensitivityError.
  • Φ[i]: common-mode phase in radians (common_mode_phase).
  • output_state[i]: output polarization as a StokesVector, from J[i] applied to input_state.
  • stats[i]: per-interval PropagatorStats (for an ensemble run, one such vector per particle).

The ensemble descriptor n_particles records the aligned ensemble size, or nothing for a scalar run. A deterministic model runs one scalar solve; an uncertain model runs per-lane scalar geometry plus one ensemble solve (docs/src/solve-workflow.md).

For an ensemble run every observable entry is Particles-valued with joint particle alignment preserved across all observables and cases. The deterministic case axis and the ensemble axis are never merged: a wavelength sweep of an uncertain model yields length(driving_values) cases, each carrying the full ensemble.

fiber holds one built fiber at the run's nominal geometry, so results carry the resolved geometry (path, frames, breakpoints, cross section, T_ref_K) without retaining per-particle paths: the propagated fiber itself for a scalar run or wavelength sweep, and the built ensemble-mean realization (every Particles model value collapsed to its mean) for an ensemble run.

Bifrost.PathIntegral.SolverParams — Type
SolverParams(; rtol, atol, h_init, h_max, h_min, safety, growth_max, shrink_min)

Adaptive step-doubling controls for the path-integral.jl propagators.

Pass a SolverParams value through the params keyword to set the tolerances, initial and maximum step sizes, minimum-step guard, and step-size update limits used by interval, piecewise, and fiber propagation.

h_init and h_max default to nothing, meaning "derive from the interval": the initial step becomes (s1 - s0) / 100 and the maximum step s1 - s0. Pass a Float64 to override either one.

All fields are Float64 solver controls and never carry uncertainty, so this struct sits outside the MCM contract; MonteCarloMeasurements.Particles live only on the physical inputs.

Default values:

FieldDefaultMeaning
rtol1e-9relative tolerance
atol1e-12absolute tolerance
h_initnothinginitial step (nothing → (s1-s0)/100)
h_maxnothingmaximum step (nothing → s1-s0)
h_min1e-12minimum step (underflow guard)
safety0.9step-update safety factor
growth_max2.0maximum step growth on accept
shrink_min0.2minimum step shrink on reject

_fiber_state_trace(f, λ_m, s_samples; input_state = Canonical.H(),

Output polarization state S(s) = stokes(J(s) * input_state) at each s in sorted s_samples ⊆ [f.s_start, f.s_end], where J(s) is the end-to-end Jones matrix from f.s_start to s.

Bifrost.PathIntegral.exp_block_upper_triangular_2x2 — Method
exp_block_upper_triangular_2x2(hM, hMω)

Return the closed-form exponential blocks for a coupled sensitivity step.

This computes the diagonal block E and off-diagonal block F of the block-upper-triangular 4×4 matrix

A = [ M   Mω ]
    [ 0   M  ]

scaled by h. The result is

exp(h·A) = [ E   F ]
           [ 0   E ]

where E = exp(hM) and F = h · φ(hM, Mω) with φ the Frechet derivative of exp along Mω:

φ(A, B) = ∫₀¹ exp((1-τ)A) · B · exp(τA) dτ

For a 2×2 M = c·I + M̃ with M̃ traceless and μ² = -det(M̃):

exp(A) = exp(c) · [cosh(μ) I + sinhc(μ) M̃]

The Frechet derivative admits a closed form in the 2×2 case (see Al-Mohy & Higham, "Computing the Fréchet derivative of the matrix exponential", 2009, §5). For A = c·I + Ã with Ã traceless and eigenvalues ±μ, one can write

φ(A, B) = α₀·B + α₁·(ÃB + BÃ) + α₂·ÃBÃ

with scalar coefficients that depend only on c and μ.

We derive the coefficients directly: because the trace part commutes, it factors as exp(c) on both E and F, leaving a traceless problem. For a traceless 2×2 Ã with eigenvalues ±μ, the identities Ã² = μ² I and the representation exp(Ã) = cosh(μ) I + sinhc(μ) Ã let us evaluate the integral in closed form using the basis {B, ÃB + BÃ, ÃBÃ}:

exp(Ã) − I = (cosh(μ) − 1) I + sinhc(μ) Ã
φ(Ã, B)   = β₀ B + β₁ (ÃB + BÃ) + β₂ ÃBÃ

Direct computation (expanding exp((1-τ)Ã) = cosh((1-τ)μ)I + sinhc((1-τ)μ)(1-τ)Ã and the mirror factor, then integrating over τ ∈ [0,1]) gives:

β₀ = sinhc(μ)                                    (coefficient of B)
β₁ = (cosh(μ) − sinhc(μ)) / (2 μ²)                (coefficient of ÃB + BÃ)
β₂ = (sinhc(μ) − cosh(μ) + μ² sinhc_int(μ)) / μ⁴  (coefficient of ÃBÃ)

where sinhc_int(μ) = ∫₀¹ τ·sinhc((1-τ)μ)·sinhc(τμ) dτ. Rather than carry that integral in closed form, we use the alternative decomposition based on Ã² = μ² I: any polynomial in Ã on a 2×2 matrix reduces to αI + βÃ, so the full φ(Ã, B) collapses to terms in {B, ÃB, BÃ, ÃBÃ} whose scalar weights integrate to elementary functions of μ.

Because this derivation is fiddly, the MCM use case motivates it (LinearAlgebra's generic exp relies on pivoting and bounds-style operations that do not lift through Particles). Instead of carrying the Frechet closed form symbolically, we fall back to a numerically exact construction: compute E = exp(hM) via exp_jones_generator, then compute F via Van Loan's identity

exp([ hM   hMω ]) = [ exp(hM)   F       ]
    [ 0    hM  ]   [ 0         exp(hM) ]

and extract F by forming the 4×4 exponential through the 2×2 closed form applied to hM and hM' plus an explicit integral representation.

Implementation: use Higham's scaling & squaring of the 2×2 closed form, combined with the identity that for A block-upper-triangular with equal diagonal blocks,

exp(s·A)^2 = [ exp(2sM)    2·exp(sM)·F_s ]
             [ 0           exp(2sM)      ]

where F_s is the off-diagonal of exp(s·A). We use s = 1 directly:

F = ∑_{k=1}^∞ (hM)^(k-1)/k! · hMω · something...

which is equivalent to the series

F = h · ∑_{k=0}^∞ (hM)^k · hMω · (hM)^j ... /(j+k+1)! ...

This is what Al-Mohy & Higham eq. (10.15) in Higham's "Functions of Matrices" computes via scaling & squaring. For 2×2 blocks the series closes in finite form because of M̃² = μ² I for the traceless part. Rather than re-derive, we compute F by the Kronecker-product identity:

vec(F) = (I ⊗ I) · L_A(hMω) · vec(I)
       ≈ h·sinhc(hM/2)  applied bilinearly

Concretely: factor M = c I + M̃ with M̃ traceless and μ² = −det(M̃). Then exp(hM) = exp(hc) · [cosh(μh)·I + sinhc(μh)·M̃·h] (note: we fold h into the coefficient so μh is dimensionless). The Frechet derivative along Mω of the scalar-function part is then elementary, and we get:

F = h · exp(hc) · (
        φ₀(hc, μh) · Mω
      + φ₁(hc, μh) · (M̃·Mω + Mω·M̃) · h
      + φ₂(hc, μh) · M̃·Mω·M̃ · h²
    )

with

φ₀(a, b) = sinhc(b)
φ₁(a, b) = (cosh(b) - sinhc(b)) / (2 b²)
φ₂(a, b) = (b·sinh(b) - 3·cosh(b) + 3·sinhc(b)) / (2 b⁴)

evaluated at a = hc (trace part absorbed into exp(hc) prefactor) and b = μh. Small-b branches use Taylor expansions for numerical stability.

Bifrost.PathIntegral.exp_cf4_step — Method
exp_cf4_step(K, s, h, J)

Advance J one fourth-order commutator-free exponential step over [s, s + h]:

J ← exp(h·(α₁K₁ + α₂K₂)) · exp(h·(α₂K₁ + α₁K₂)) · J,

with Kᵢ = K(s + cᵢh) at the Gauss–Legendre nodes c = 1/2 ∓ √3/6 and weights α = 1/4 ∓ √3/6: a two-exponential commutator-free Magnus method of fourth order (test/testsolverconvergence.jl measures the order). Each factor is the closed-form exp_jones_generator, so the step stays unitary and lifts through MCM Particles; for a constant K both factors are exp(hK/2) and the step is exact.

K must return a 2×2 local Jones generator. The return value is a static 2×2; for lanes (_Lanes) of K and J it is the step taken lane by lane.

Bifrost.PathIntegral.exp_jones_generator — Method
exp_jones_generator(A)

Return the closed-form exponential of a 2×2 Jones generator.

For an exactly traceless matrix A, Cayley-Hamilton gives A^2 = -det(A) I, so

exp(A) = cosh(μ) I + sinh(μ)/μ * A, where μ^2 = -det(A).

This implementation also removes any tiny numerical trace drift by factoring out exp(tr(A)/2) and applying the closed form to the centered traceless part.

Accepts any 2×2 AbstractMatrix with a Complex eltype and returns a static 2×2 (SMatrix); lifts elementwise through MCM Particles entries.

Bifrost.PathIntegral.exp_sensitivity_cf4_step — Method
exp_sensitivity_cf4_step(K, Kω, s, h, J, G)

Advance (J, G) one fourth-order commutator-free step over [s, s + h]: the step of exp_cf4_step applied to the coupled system d/ds [G; J] = A·[G; J] with the 4×4 block-upper-triangular generator

A = [ K   Kω ]
    [ 0   K  ]

each factor exponentiated in closed form by exp_block_upper_triangular_2x2. Lanes (_Lanes) step lane by lane. The motivation for avoiding LinearAlgebra.exp on the 4×4 matrix is MCM compatibility: the generic Padé approximation relies on operations (typemax, isfinite on matrix norms, pivoting) that do not lift through Particles. The closed form is also faster and more accurate than the generic Padé even for pure Float64 inputs.

Bifrost.PathIntegral.output_dgd — Method
output_dgd(J, G; hermitianize = true)

Return differential group delay as the real eigenvalue spread of the PMD generator.

H = -i·J⁻¹·G.

Note: under MCM, eigvals on a Matrix{<:Particles} hits LinearAlgebra routines that do not lift elementwise (typemax, pivoting). For uncertain propagations, compute the mean DGD per-sample via bymap at the call site, or extract the Hermitian eigenvalues by hand for the 2×2 case (closed form: eigenvalues of a 2×2 Hermitian matrix are (tr/2) ± √((tr/2)² − det)).

Bifrost.PathIntegral.pmd_generator — Method
pmd_generator(J, G; hermitianize = true)

Compute the PMD generator H = -im * (J \ G).

Set hermitianize = true to replace H by (H + H') / 2, which suppresses small numerical anti-Hermitian drift before DGD extraction.

For the 2×2 case the J \ G solve uses a comparison-free closed form (_solve_2x2), so the generator lifts through MCM Particles; larger matrices fall back to the generic \ (Float64 paths only).

Bifrost.PathIntegral.propagate_fiber — Method
propagate_fiber(model::FiberModel; λ_m, input_state = Canonical.H(),
                sensitivity = true, verbose = true, params = SolverParams())
    -> FiberPropagationResults

Execute a fiber model. λ_m is the operating wavelength in metres: a scalar (one deterministic case) or an AbstractVector (a deterministic wavelength sweep — the case axis).

sensitivity = true integrates G = ∂ωJ alongside J, for J_dw and DGD. sensitivity = false integrates J alone, for the PTF without the ∂ω solve, and leaves J_dw and dgd as nothing. J sets the step size in both modes (G, in seconds, is far smaller), so J is the same either way.

A fully deterministic model runs a single ordinary scalar solve (docs/src/solve-workflow.md). An uncertain model realizes every aligned particle index as its own scalar fiber (scalarize → Fiber: its own trajectory, connector solutions, frames, and phases), then integrates the optics once, for all particles, through a single Particles-valued solve over the stacked per-lane generators on the nominal reference grid. Every observable is exact per particle to solver tolerance, and every entry comes back Particles-valued with joint particle alignment preserved.

A failure while realizing one lane's geometry is rethrown as a ParticleSolveError carrying the particle index; lane feasibility is not checked in advance.

Bifrost.PathIntegral.propagate_fiber — Method
propagate_fiber(fiber; λ_m, verbose = true, params = SolverParams())
propagate_fiber(fiber; λ_m::AbstractVector, input_state = Canonical.H(),
                sensitivity = true, ...)

Propagate a path-backed Fiber at operating wavelength λ_m.

With a scalar λ_m the return is (J_final, stats), one PropagatorStats per interval of fiber_breakpoints(fiber). The fiber is integrated in its material frame, which turns with the spin and mechanical twist (src/fiber/material-frame.jl): there the generator is generator_K(fiber, λ_m) with its linear-birefringence axes turned back by the accumulated angle, plus the frame's own circular term, so the ellipticity of a spun straight is constant and its oscillation costs no steps; on a helix with a constant spin rate it repeats with a period, and an interval holding several periods is integrated over one and raised to their number. J_final is the lab-frame (transported-frame) Jones matrix.

With a vector λ_m the fiber is swept over the given wavelengths (a deterministic case axis) and the return is a FiberPropagationResults holding every observable (Jones matrix, sensitivity, DGD, common-mode phase, and the output polarization state of input_state) eagerly. Each sample runs the coupled sensitivity solve, or with sensitivity = false the Jones solve alone, leaving J_dw and dgd as nothing. input_state and sensitivity participate only in sweep mode; a scalar-λ_m call ignores them and solves J alone. Julia keywords do not dispatch, so both modes share this method and branch on the runtime type of λ_m.

λ_m is always deterministic; a Particles wavelength is rejected (uncertainty belongs on FiberModel, and first-order wavelength sensitivity is carried by G = ∂ωJ).

Lumped jump matrices are a primitive-solver concept: the fiber layer derives its breakpoint grid internally, so there is no coherent key a caller could supply here. Callers who need lumped elements drive propagate_piecewise directly with an explicit grid.

Bifrost.PathIntegral.propagate_interval! — Method
propagate_interval!(K, s0, s1, J0; params = SolverParams())

Propagate dJ/ds = K(s) * J over one smooth interval.

The method is fourth-order commutator-free exponential step doubling (exp_cf4_step) with phase_insensitive_error. Step controls and tolerances are carried by params::SolverParams. It returns (J_final, stats), where stats is a PropagatorStats for the interval; J0 is left unchanged. J0 is a 2×2 matrix (J_final is then a Matrix), or lanes (_Lanes) of static 2×2s advanced through one shared step sequence, for a K whose value is lanes too.

Bifrost.PathIntegral.propagate_interval_sensitivity! — Method
propagate_interval_sensitivity!(K, Kω, s0, s1, J0; G0, params = SolverParams())

Propagate the coupled Jones and angular-frequency sensitivity system over one interval.

The equations are dJ/ds = K(s) * J and dG/ds = Kω(s) * J + K(s) * G. Step controls and tolerances are carried by params::SolverParams. The function returns (J_final, G_final, stats) and leaves both initial values unchanged; they are 2×2 matrices or lanes, as for propagate_interval!.
