Plots

Opt-in developer diagnostics, loaded with using Bifrost.Plots. These record data for a human to inspect and render nothing themselves. For figures, load Plots.jl alongside Bifrost (plot(fiber), plot(dgd(results))) or PlotlyBase for inspect(path).

Bifrost.Plots.StepRecord — Type
StepRecord

One trial step of the adaptive step-doubling controller: the position it was attempted from, the step size tried, the phase-insensitive error between the full step and two half steps, the tolerance that error was judged against, and whether the step was accepted.

source
Bifrost.Plots.collect_adaptive_steps — Method
collect_adaptive_steps(K, s0, s1, J0; kwargs...) -> (J_final, records)

Propagate J0 from s0 to s1 under generator K, recording every trial step — accepted and rejected — as a StepRecord.

Mirrors the production step controller (same error metric, same safety and growth/shrink factors) without modifying it, so the returned J_final matches an ordinary propagate_interval! over the same interval while records exposes the step history the solver otherwise discards.
