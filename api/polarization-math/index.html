PolarizationMath

Supported polarization representations are Jones, Stokes, Mueller, coherency-matrix, and Poincaré axis–angle. A narrow conversion API (jones, stokes, mueller, delta_phi, coherency, azimuth_ellipticity) is decoded by multiple dispatch, and * is overloaded so operators act on states — and on one another — across formalisms, returning the natural result type.

Convention

Bifrost.PolarizationMath — Module
PolarizationMath

Jones, Stokes, Mueller, coherency, and Poincaré representations of polarization.

Conventions

This is the single statement of Bifrost's optical conventions. The fiber generators (Bifrost.FiberPath), the docs, and the tests cite it rather than restating it.

  • Time dependence e^{−iωt}. A Jones vector (Ex, Ey) holds the complex amplitudes of the real field Re[(Ex, Ey) e^{i(kz − ωt)}]. Propagating a distance s with propagation constant β multiplies an amplitude by e^{+iβs}, so a slow (higher-β) axis gains phase relative to a fast one.

  • Handedness is judged looking toward the source (Born & Wolf, Principles of Optics, 7th ed., §1.4): right-circular light rotates clockwise. Hence R() = [1, −i]/√2 and L() = [1, i]/√2.

  • Stokes parameters, with S3 = I_R − I_L:

    S0 = |Ex|² + |Ey|²        S1 = |Ex|² − |Ey|²
S2 = 2 Re(Ex Ey*)         S3 = +2 Im(Ex Ey*)

    Right-circular light is the Poincaré north pole: S3 = +1, ellipticity +π/4.

  • Field-defined parameters. AzimuthEllipticity and DeltaPhiState are defined by the real field, so their parameters do not depend on the time sign.

  • Other references. A reference using e^{+iωt} (pypolar's default, for one) writes every Jones vector and matrix as the complex conjugate of the one here; Stokes and Mueller quantities agree.

Enforced by the T-PHYSICS tests "handedness from the real field's rotation" and "DeltaPhiState canonical values" (test/test_polarization_math.jl) and by the quarter-wave fiber test in test/test_birefringence_signs.jl.

source

All constructors, conversions, and operators lift through MonteCarloMeasurements.Particles; the sole exception is jones(::MuellerMatrix) (the Cloude coherency-eigenvector method), which nominalizes Particles before its eigendecomposition.

Canonical fully polarized states (H, V, D, A, R, L) and ideal optical elements (linear_polarizer, retarder, qwp, hwp, and the general lossless rotator with its uniform draw rotator_random) live in the Canonical submodule; bring them into scope with using Bifrost.PolarizationMath.Canonical.

Validity checks

Each representation enforces what physically constrains it, and nothing more:

  • StokesVector requires S0 ≥ √(S1²+S2²+S3²) (degree of polarization ≤ 1).
  • CoherencyMatrix requires a Hermitian, positive-semidefinite matrix.
  • JonesVector is unconstrained: any nonzero complex 2-vector is a valid fully polarized state, and its magnitude carries power, so normalization is not forced.
  • Jones and Mueller matrices are not required to be unitary — lossy elements such as linear_polarizer are valid by design. Pass the option :is_unitary to a matrix constructor (JonesMatrix(m, :is_unitary), likewise MuellerMatrix and CoherencyMatrix) to test unitarity opt-in: it returns the matrix when unitary and false otherwise. JonesMatrix(m, :det_is_unity) likewise tests det J = 1. Options stack, and all must pass: JonesMatrix(m, :is_unitary, :det_is_unity) tests SU(2) membership, as rotator! requires.
  • Acting a MuellerMatrix on a state enforces the Cloude criterion: the 4×4 Hermitian coherency matrix associated with M must be positive semidefinite. This rejects physically unrealizable Mueller matrices while still allowing a polarizer to raise the degree of polarization of unpolarized light.

Bifrost.PolarizationMath.AzimuthEllipticity — Type
AzimuthEllipticity(azimuth, ellipticity)

Pure state described by the polarization ellipse: azimuth ψ (orientation of the major axis from horizontal) and ellipticity χ, with the Poincaré mapping longitude 2ψ and latitude 2χ. Right-circular has χ = +π/4.

source
Bifrost.PolarizationMath.CoherencyMatrix — Type
CoherencyMatrix((Jxx, Jxy, Jyx, Jyy))
CoherencyMatrix(m, :is_unitary)

2×2 Hermitian coherency (polarization density) matrix stored row-major, Jₐᵦ = ⟨Eₐ Eᵦ*⟩. The bridge between Jones states and partially polarized Stokes vectors: a rank-1 matrix is a pure state, lower rank is partial.

With the option :is_unitary the constructor returns the matrix when it is unitary (ρ†ρ = I, which for a Hermitian positive-semidefinite coherency matrix means ρ = I) and false otherwise.

Bifrost.PolarizationMath.DeltaPhiState — Type
DeltaPhiState(θ, ϕ)

Pure polarization state in the H/V Jones basis with global phase fixed so that the H component is real and non-negative:

|ψ⟩ = cos(θ)|H⟩ + exp(−im*ϕ) sin(θ)|V⟩.

Use this when you want a minimal, physically interpretable parameterization of a pure polarization state. The real parameter θ sets the H/V amplitude ratio, while the real parameter ϕ is the phase lead of the V oscillation over the H oscillation: the real field is (cos θ cos(ωt), sin θ cos(ωt + ϕ)). ϕ is defined by the physical field, not by the Jones amplitudes, so under the e^{−iωt} convention of Bifrost.PolarizationMath ϕ = arg(EH) − arg(EV), and ϕ = +π/2 (V leads H by a quarter period) is right-circular.

θ ∈ [0, π/2] is enforced. ϕ may be any real number.

At θ = 0 or θ = π/2, ϕ is physically undefined (it multiplies a zero component) but is still stored as given.

The corresponding normalized Stokes vector is

(S1, S2, S3) =
    (cos(2θ), sin(2θ)cos(ϕ), sin(2θ)sin(ϕ)),

using the file-header convention S3 = +2 Im(Ex Ey*). Hence 2θ is the polar angle from the S1 axis on the Poincaré sphere, and ϕ is the azimuth about that axis.

Angle conventions across this module agree for linear states: a DeltaPhiState with ϕ = 0 is the linear state whose physical axis lies at angle θ from horizontal, so DeltaPhiState(θ, 0) equals the state transmitted by Canonical.linear_polarizer(θ) and the fast-axis eigenpolarization of Canonical.retarder(θ, δ). Note the angles are not the same kind of object: here θ is an amplitude angle whose Poincaré polar angle is 2θ, whereas the θ of linear_polarizer/retarder is a physical-space azimuth; the two coincide numerically only on the linear (ϕ = 0) equator. The state phase ϕ is likewise distinct from the retarder retardation δ.

Bifrost.PolarizationMath.JonesMatrix — Type
JonesMatrix(m11, m12, m21, m22)
JonesMatrix((m11, m12, m21, m22))
JonesMatrix(m, opts::Symbol...)

2×2 complex Jones operator stored row-major.

With options the constructor returns the matrix when it passes every one and false otherwise: :is_unitary tests J†J = I, :det_is_unity tests det J = 1. They are opt-in, not enforced, because lossy elements are valid Jones matrices: Canonical.linear_polarizer is a singular, non-unitary projector by design. JonesMatrix(m, :is_unitary, :det_is_unity) tests SU(2) membership: a lossless element with no global phase.

Bifrost.PolarizationMath.mueller_to_axis_angle — Method
mueller_to_axis_angle(M) -> (axis, angle)

Rotation axis (n1, n2, n3) on the Poincaré sphere and rotation angle of a pure-retarder Mueller matrix M. Inverse of axis_angle_to_mueller. Throws an ArgumentError if M is not a proper rotation (depolarizing or diattenuating). Validity checks nominalize Particles; the returned axis and angle carry the full ensemble. Bifrost.PolarizationMath.Canonical.retarder — Method
retarder(θ, δ)

Jones matrix of a linear retarder with fast axis at angle θ from horizontal and retardation δ (the slow axis lags the fast axis by δ: in the e^{−iωt} convention it gains phase e^{+iδ/2} and the fast axis e^{−iδ/2}). The global phase is fixed so zero retardation is the identity. The fast-axis angle matches the linear-state convention of Bifrost.PolarizationMath.DeltaPhiState: DeltaPhiState(θ, 0) is the fast-axis eigenpolarization. The retardation δ is an element property, not the state phase ϕ.

Bifrost.PolarizationMath.Canonical.rotator — Method
rotator(α)

Jones matrix of the general lossless rotator named by the Czegledi 4-vector α = (α₀, α₁, α₂, α₃), a unit quaternion:

J = α₀·I − i(α₁σ₁ + α₂σ₂ + α₃σ₃)

with σ₁, σ₂, σ₃ the Pauli matrices of the Stokes parameters S1, S2, S3 — the basis mueller uses, fixed by the conventions of Bifrost.PolarizationMath. α is normalized first, so its scale carries no meaning; (1, 0, 0, 0) is the identity. The rotation of the Poincaré sphere is the one axis_angle_to_mueller(â, 2·acos(α₀)) names, with â the unit axis of (α₁, α₂, α₃); a linear retarder(θ, δ) is rotator((cos(δ/2), sin(δ/2)·cos 2θ, sin(δ/2)·sin 2θ, 0)).

det J = ‖α‖² = 1, so J is in SU(2). Each entry is linear in α, with no acos and no branch, so an uncertain α lifts through Particles entry by entry.

Bifrost.PolarizationMath.Canonical.rotator_random — Method
rotator_random(rng)

A rotator drawn uniformly (Haar measure on SU(2)) from rng. A normalized 4-D Gaussian is uniform on the unit 3-sphere of quaternions, so the rotated Stokes vector of any fixed state is uniform on the Poincaré sphere.
