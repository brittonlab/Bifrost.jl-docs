Constants

Physical constants used throughout the codebase (speed of light, vacuum permittivity, etc.), re-exported under the u namespace at the Bifrost top level.

Bifrost.Constants.u — Constant
u

Singleton bundle of fundamental physical constants (CODATA 2022, SI units). Access fields directly:

julia> using Bifrost

julia> u.c
2.99792458e8

See NaturalConstants for the available fields (c, ħ, kB).

source
Bifrost.Constants.NaturalConstants — Type
NaturalConstants

Bundle of fundamental physical constants in SI units, stored as Float64.

Fields

  • c: speed of light in vacuum, m/s
  • ħ: reduced Planck constant, J·s
  • kB: Boltzmann constant, J/K
