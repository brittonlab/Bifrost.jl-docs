FiberPath

Fiber assembly: binds an authored PathBuilder (or a built Path) to a FiberCrossSection and reference temperature, assembles the fiber-level bend and twist generators K(s) and Kω(s), and applies meta-driven perturbations and thermal length scaling when the Fiber constructor builds the authored geometry.

The module docstring, which states the generators' sign conventions, is rendered in The transverse frame and the birefringence gauge, §5.

Bifrost.FiberPath.Fiber — Method
Fiber(model::FiberModel) -> Fiber

The boundary crossing from model to geometry: build the fiber of a fully deterministic model. This is the funnel propagate_fiber itself builds through — once for a deterministic model, per scalarized particle for an ensemble — and the way one realization is materialized (Fiber(scalarize(model, i))). An uncertainty-carrying model is rejected.

Bifrost.FiberPath.Fiber — Method
Fiber(pb::PathBuilder; cross_section, T_ref_K=DEFAULT_T_REF_K) -> Fiber

Build a fiber from the authored path pb, applying perturbation meta during the build.

Thermal :T_K annotations are resolved here using α_lin = cte(cross_section.cladding_material, T_ref_K) — each thermal segment's length-dimensioned fields are scaled by 1 + α_lin·ΔT. Field-level MetaAdd/MetaMul are then applied by the geometry build. A jumpto! connector carrying its own :T_K thermally expands too: it re-solves to its nominal arc length scaled by τ while still landing at its fixed target.

Per-segment axial tension :tension (absolute Newtons, e.g. MetaAdd(:tension, 0.5)) is interpreted here too and plays a dual role exactly like :T_K: it elongates the segment by (1 + ε) with the axial strain ε = F / (π·r_cladding²·E) (E = youngs_modulus(cladding_material, T_ref_K), r₁ = r_cladding(cross_section)) and it sets the segment's axial-tension photoelastic birefringence (a linear birefringence on the bend eigen-axis, so it is zero on a straight segment; recovered downstream via tension(f, s)). Thermal and tension length scalings compose multiplicatively. A jumpto! connector carrying :tension elongates the same way. The :tension meta is left on the segment for on-demand recovery, as :T_K is.

Bifrost.FiberPath.FiberModel — Type
FiberModel(pb::PathBuilder; cross_section, T_ref_K = DEFAULT_T_REF_K) -> FiberModel

Bundle the authored path pb with its cross section and reference temperature without building anything. Fiber(model) builds exactly what Fiber(pb; ...) binds, so wrapping a builder in a model is always a drop-in substitution for binding it directly. The model stores a deep copy of pb as path, so later authoring on pb does not affect the model.

A FiberModel is the uncertainty-carrying form of a fiber: any model value — segment fields, MetaAdd/MetaMul payloads (including :T_K and :tension), start coordinates, connector targets, spin and twist rates, cross-section fields — may be a MonteCarloMeasurements.Particles ensemble. All ensemble values must share one aligned particle count (see particle_count); T_ref_K must be deterministic (uncertain temperature belongs on segment :T_K meta).

Uncertainty must be carried by Particles values directly: a raw distribution payload (e.g. MetaAdd(:T_K, Normal(0.0, 2.0))) is rejected — wrap it as Particles(n, Normal(0.0, 2.0)) so the ensemble size and joint particle alignment are explicit. Function-valued rates must return deterministic values; a function returning Particles is rejected (MCM hidden inside functions cannot be scalarized).

Execute the model with propagate_fiber(model; λ_m): a deterministic model runs one scalar solve, an uncertain model runs the ensemble execution (docs/src/solve-workflow.md). Crossing from model to geometry happens through Fiber(model) — the scalar-only funnel propagate_fiber itself builds through — and one realization of an uncertain model is materialized with scalarize (Fiber(scalarize(model, i))).

Bifrost.FiberPath.MaterialPeriodError — Type
MaterialPeriodError(a, period, mismatch)

The material-frame generator did not repeat after the period declared for the interval starting at reference coordinate a: at a point and one period later it differed by mismatch, relative to its size. Raised instead of raising a wrong one-period propagator to a power.

Bifrost.FiberPath._nominal_realization — Method
_nominal_realization(model::FiberModel) -> FiberModel

The ensemble-mean realization: it recursively projects every Particles value in the path with mcmpmean (including MetaAdd and MetaMul payloads), giving the deterministic model whose build is the nominal geometry. propagate_fiber stamps FiberPropagationResults.fiber with this build for ensemble runs. Bifrost.FiberPath._projected — Method
_projected(x, resolve) -> value
_scalarized(x, i) -> value

Structural ensemble projection: replace every Particles value reachable in x with resolve(x) — its i-th particle for _scalarized(x, i), its ensemble mean for _nominal_realization — rebuilding containers and model structs around the projected leaves. Uncertainty-carrying types without a reconstruction method error loudly rather than being silently passed through.

Bifrost.FiberPath.circular_birefringence_generator — Method
circular_birefringence_generator(Δβc) -> 2×2 matrix

Local Jones generator for circular birefringence (optical activity) with rotation rate Δβc. Real antisymmetric — a pure SO(2) rotation generator. Used by the mechanical-twist generator.

Δβc = β_LC − β_RC is signed (brittonlab/Bifrost.jl#87; sign conventions: Bifrost.FiberPath). A positive Δβc (left-circular slower) rotates the axes clockwise (e1 → −e2, r-rotatory) at rate Δβc/2 per unit length. A right-handed mechanical twist gives Δβc < 0, hence the l-rotatory rotation that follows the twist (Ulrich & Simon, doi:10.1364/AO.18.002241).

Bifrost.FiberPath.common_mode_phase — Method
common_mode_phase(fiber; λ_m)

Accumulate the common-mode (polarization-averaged) optical phase ∫₀ᴸ β_mean(s) ds in radians along fiber at operating wavelength λ_m (metres).

β_mean(s) is the polarization-averaged propagation constant the traceless Jones generators drop: the fundamental LP₀₁ constant β₀ = propagation_constant(cross_section, λ_m, T(s)) = k₀·n_eff, plus the scalar isotropic photoelastic shift (frozen axisymmetric draw stress, bend stress, and any applied axial tension; see [β_shift_common_mode]). The common-mode shift raises both modes equally, so it stays out of the differential generator and leaves the DGD untouched.

The integral runs over the same segment-table rows the differential generator uses (generator_K, issue #125): each finite-length authored segment contributes β_mean(s_mid)·L0, where L0 is the segment's physical arc length on a built path and s_mid = L0/2 is its physical midpoint (zero-length rows add nothing). Length-changing meta (:T_K thermal expansion, :tension elongation) scales the segment length fields at build, so it is already in L0 and enters the optical path length exactly and per particle under MCM — the per-particle physical-length fluctuation flows into the spread of Φ (and of the transit time τ = Φ/ω), matching the differential path.

Temperature, tension, and ellipticity are piecewise-constant per geometry segment, and curvature is constant on straight and constant-radius bend segments, so on those segments β_mean is constant and β_mean(s_mid)·L_phys is exact (not a quadrature). On varying-curvature segments (G2 connectors, helices, catenaries) the bend-stress term varies within the segment, so the midpoint value is a second-order-accurate sample of that small correction. The product and sum are ordinary arithmetic (no scalar coercions or comparisons), so the return value lifts through MCM Particles when its inputs are.

Bifrost.FiberPath.generator_K — Method
generator_K(fiber, xs::StepIndexCrossSection, λ_m) -> (u -> 2×2 matrix)

Assemble the step-index local Jones generator as a closure of the reference (nominal) arc length u. Each authored segment is propagated in its own fixed reference interval [u0, u0+L0]; the closure maps u to the physical local position sl = u - u0 and evaluates the bend, twist, ellipticity, and tension terms there. On a built path L0 is the segment's physical arc length, so u coincides with physical arc length and the generator is returned directly; length-changing meta (:T_K, :tension) is already in the built geometry (issue #125). The reference grid is fiber_breakpoints, so the propagator's interval decomposition is unchanged.

Bifrost.FiberPath.linear_birefringence_generator — Method
linear_birefringence_generator(Δβ, c2φ, s2φ) -> 2×2 matrix

Local Jones generator for a linear retarder with retardance per unit length Δβ and eigen-axes oriented at angle φ in the propagation frame, encoded via c2φ = cos(2φ) and s2φ = sin(2φ). Traceless, anti-Hermitian times i. A static 2×2 (SMatrix), like every generator term. Shared by the bend, core-ellipticity, and asymmetric-thermal-stress generators.

Δβ is signed: Δβ > 0 makes the axis at φ slow. Sign conventions: Bifrost.FiberPath.

Bifrost.FiberPath.scalarize — Method
scalarize(model::FiberModel, i::Integer) -> FiberModel

The scalar realization of model at aligned particle index i: every Particles value anywhere in the model is replaced by its i-th particle, so the result carries no uncertainty and can be built and propagated as an ordinary scalar fiber (Fiber(scalarize(model, i))). One index selects the whole joint realization — per-value index mixing is deliberately impossible.

A fully deterministic model is returned unchanged for any i.

Bifrost.FiberPath.temperature — Method
temperature(f::Fiber, s) -> T

Temperature (K) at fiber arc length s, derived on demand: T_ref_K + ΔT, where ΔT is the :T_K excursion carried by the segment containing s (located via local_segment(f.path, s)). A fiber with no :T_K returns T_ref_K everywhere — meta_combine(0.0, seg, :T_K) collapses to 0.0 when the segment carries none, so no sentinel is needed. The cross-section birefringences are evaluated at this temperature (asymmetric thermal stress ∝ |T_soft − T|, and the indices shift with T), so a :T_K segment's optical response — not only its length — reflects the excursion. ΔT may be Particles; the returned value carries it into the MCM-safe cross-section T_K slot. Sibling of curvature(f, s): no thermal state is stored on Fiber.

source
Bifrost.FiberPath.tension — Method
tension(f::Fiber, s) -> F

Axial tension (N) at fiber arc length s, derived on demand from the :tension meta carried by the segment containing s (via local_segment(f.path, s)); 0 where none is present — meta_combine(0.0, seg, :tension) collapses to 0.0 when the segment carries none, so no sentinel is needed. Consumed by tension_generator_K (axial-tension photoelastic birefringence). May be Particles. Sibling of temperature(f, s) — no tension state is stored on Fiber.

Bifrost.FiberPath.β_shift_common_mode — Method
β_shift_common_mode(fiber, s, λ_m)

The return value is the polarization-averaged propagation-constant shift (rad/m) at arc length s, added to the unperturbed β_mean = k₀·n_eff by [common_mode_phase].

Sums the active isotropic photoelastic mechanisms. The axisymmetric frozen draw stress ([n_shift_stress_thermal], present whenever the core and cladding thermal-expansion coefficients differ) and any applied axial tension ([n_shift_tension_axial]) are dimensionless index shifts δn, accumulated and converted to a propagation-constant shift by the single k₀ = 2π/λ_m factor applied here; the bend-stress shift on curved segments ([β_shift_stress_bend]) is already a 1/m shift and is added directly. Temperature is temperature(f, s), the bend curvature is curvature(f.path, s), and tension is tension(f, s); the bend and tension terms are skipped where the segment is straight or untensioned. Pure arithmetic, so it lifts through MCM Particles when its inputs are.
