Utils

Layer-agnostic validation vocabulary — range checking and a "not modeled" exception — reused across the material, cross-section, and fiber layers.

Bifrost.Utils.UnsupportedPropertyError — Type
UnsupportedPropertyError(property, owner)

Thrown when property (e.g. "cte") is intentionally not modeled for owner (a human-readable name such as "fluorine-doped silica").

This is distinct from a MethodError: the property is a deliberate omission from the model — either physically absent or not yet implemented — not an accidental dispatch failure. Callers may catch it by type to degrade gracefully rather than string-matching an error message.

Bifrost.Utils.ValidRange — Type
ValidRange(lo, hi, name)

Closed interval [lo, hi] bounding the domain over which a physical model is valid, for a quantity labelled name (used only in error messages).
